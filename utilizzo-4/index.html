Utilizzo dell'IA 4 · Piccole app e siti web

Si chiede all'IA di scrivere una pagina web, la si scarica come file e la si apre dal desktop. Due esercizi: una lista delle cose da fare e un sito per presentare te stesso o la tua attività.

Che cos'è un file HTML

Un file HTML è una pagina web salvata come file sul computer. Il browser (Chrome, Edge, Firefox) lo apre anche senza internet. Dentro ci sono tre parti, tutte scritte come testo:

  • HTML: il contenuto, cioè titoli, testi, pulsanti, caselle;
  • CSS: l'aspetto, cioè colori, caratteri, spazi;
  • JavaScript: il comportamento, cioè cosa succede quando premi un pulsante.

L'IA scrive tutte e tre le parti in un solo file. Tu non devi leggere il codice: lo provi e, se qualcosa non va, descrivi all'IA che cosa vedi.

Dalla risposta dell'IA al desktop (Windows)
  1. Scarica il file. Claude mostra la pagina in un riquadro a lato; ChatGPT di solito dà un file o un link da scaricare. Cerca il pulsante per scaricare. Il file finisce nella cartella Download.
  2. Controlla il nome. Deve finire con .html, per esempio cose-da-fare.html. Per vedere la fine del nome, in Esplora file apri Visualizza → Mostra → Estensioni nomi file. Se il nome finisce con .txt, rinominalo e cambia la fine in .html.
  3. Spostalo sul desktop. Apri la cartella Download e trascina il file sul desktop.
  4. Aprilo. Fai doppio clic sul file: si apre nel browser. Se invece si apre il Blocco note, fai clic con il tasto destro sul file, scegli Apri con e scegli il browser.

Quando l'IA ti dà una versione nuova, scaricala, cancella il file vecchio dal desktop e metti al suo posto quello nuovo, con lo stesso nome.

1Una lista delle cose da fare

Un'app semplice: scrivi una cosa da fare, la aggiungi all'elenco, la segni come fatta quando l'hai fatta. Niente scadenze, niente avvisi, niente finestre che si aprono da sole.

Chiedi

Crea una piccola app per la lista delle cose da fare, in un solo file HTML che funzioni anche senza internet e senza librerie o file esterni. L'app deve permettere di: - scrivere una cosa da fare e aggiungerla con un pulsante o con il tasto Invio; - segnare una cosa come fatta o non fatta con una casella di spunta; le cose fatte devono apparire barrate; - eliminare una cosa con un pulsante accanto. Salva l'elenco nella memoria del browser (localStorage), così le cose restano quando chiudo e riapro il file. Non aggiungere scadenze, promemoria, avvisi o finestre che si aprono. Tutte le scritte devono essere in italiano. Dammi il file HTML da scaricare.

Scarica e apri

Segui i passi di «Dalla risposta dell'IA al desktop». Chiama il file cose-da-fare.html.

Controlla

  1. Aggiungi tre cose: le prime due con il pulsante, la terza con il tasto Invio.
  2. Segna la seconda come fatta: deve apparire barrata.
  3. Elimina la terza.
  4. Premi Aggiungi con il campo vuoto: non deve comparire una riga vuota.
  5. Chiudi il browser e riapri il file dal desktop: devono esserci ancora le prime due cose, con la seconda barrata.

Se qualcosa non funziona, scrivi all'IA che cosa hai fatto e che cosa vedi. Per esempio:

Quando chiudo e riapro il file, l'elenco è vuoto: le cose che avevo aggiunto non ci sono più. Correggi questo problema e dammi di nuovo il file HTML completo.

Se non riesci a farla funzionare, qui c'è una versione già pronta da confrontare con la tua:

cose-da-fare.html esempio pronto
Dove sono salvati i dati. Nella memoria del browser, sul tuo computer: non vanno su internet. Restano finché apri il file con lo stesso browser. Se lo apri con un altro browser o su un altro computer, l'elenco è vuoto. Se cancelli i dati di navigazione del browser, l'elenco si cancella. Tieni il file sempre nello stesso posto e con lo stesso nome: in alcuni browser, se lo sposti, l'app riparte vuota.

Migliora l'app

Chiedi una modifica alla volta, nella stessa chat. Dopo ogni modifica scarica il file nuovo, sostituisci quello sul desktop e ripeti i controlli. La frase finale di ogni richiesta serve a non perdere le cose già scritte.

Modifica 1 · Contatore

Aggiungi sotto il titolo una riga che dica quante cose restano da fare, per esempio «2 da fare su 5». Mantieni lo stesso modo di salvare i dati e dammi il file HTML completo.

Modifica 2 · Cose fatte in fondo

Mostra le cose fatte in fondo all'elenco, sotto quelle da fare. Mantieni lo stesso modo di salvare i dati e dammi il file HTML completo.

Modifica 3 · Togliere le cose fatte

Aggiungi in fondo un pulsante «Togli le cose fatte» che elimina dall'elenco tutte le cose segnate come fatte, senza chiedere conferma. Mantieni lo stesso modo di salvare i dati e dammi il file HTML completo.

Modifica 4 · Correggere un testo

Fai in modo che, con un doppio clic su una cosa da fare, il suo testo diventi modificabile; con Invio si salva il testo nuovo. Mantieni lo stesso modo di salvare i dati e dammi il file HTML completo.

Modifica 5 · Aspetto

Cambia l'aspetto: sfondo azzurro chiaro, pulsanti blu scuro, caratteri più grandi e più spazio tra le righe. Non cambiare il funzionamento. Mantieni lo stesso modo di salvare i dati e dammi il file HTML completo.

2Un sito di presentazione

Una pagina per farti conoscere da chi potrebbe offrirti un lavoro o un incarico, oppure per presentare la tua attività ai clienti. Non è un curriculum. Un curriculum elenca i lavori fatti; questa pagina dice chi sei, che cosa sai fare, che cosa offri e che cosa ti appassiona.

Il lavoro più importante lo fai prima di aprire l'IA: scrivere le informazioni vere. L'IA le mette in ordine e dà l'aspetto alla pagina.

Passo 1 · Prepara le informazioni

Copia uno dei due modelli in un documento e compilalo. Scrivi cose concrete: invece di «sono preciso», scrivi che cosa fai con precisione e un esempio. Lascia vuoto quello che non vuoi mostrare.

Modello A · Per presentare te stesso

Nome e cognome: Che cosa offro (il lavoro o il servizio che propongo, in una frase): Che cosa so fare (tre o quattro cose concrete): Un esempio di lavoro fatto bene (che cosa ho fatto e che risultato ha avuto): Chi sono (due o tre frasi: dove vivo, come lavoro, che cosa mi piace del mio lavoro): Le mie passioni (anche fuori dal lavoro): Contatti da mostrare (email, telefono, profilo LinkedIn):

Modello B · Per presentare un'attività

Nome dell'attività: Che cosa offriamo, in una frase: Servizi o prodotti (con i prezzi, se volete mostrarli): Chi siamo (chi lavora nell'attività e da quanto tempo): Che cosa ci distingue (fatti concreti: tempi di intervento, materiali usati, certificazioni): Zona servita o indirizzo, giorni e orari: Contatti da mostrare (telefono, email, WhatsApp):

Se vuoi fare pratica senza usare i tuoi dati, usa questo esempio inventato per il modello A:

Nome e cognome: Laura Bianchi Che cosa offro: mi occupo dell'amministrazione di piccole aziende: fatture, pagamenti e rapporti con i fornitori. Che cosa so fare: - tenere in ordine fatture e scadenze dei pagamenti; - preparare i documenti per il commercialista; - fare tabelle e riepiloghi con Excel e Google Sheets; - usare l'intelligenza artificiale per leggere documenti e trasformarli in tabelle. Un esempio di lavoro fatto bene: in un'azienda di ferramenta ho organizzato i solleciti ai clienti con un calendario fisso; in un anno il tempo medio di pagamento è sceso da 60 a 25 giorni. Chi sono: vivo a Verona. Mi piace mettere ordine nei documenti e spiegare i numeri in modo semplice a chi non è del mestiere. Le mie passioni: escursioni in montagna, cucina, volontariato nella biblioteca del quartiere. Contatti: laura.bianchi@example.com, 333 1234567

Attenzione ai dati personali. Se un giorno metti il sito su internet, chiunque potrà leggerlo. Metti solo le informazioni che sei disposto a mostrare a tutti: per esempio, l'email sì, l'indirizzo di casa no.

Passo 2 · Chiedi

Usa il prompt adatto, poi incolla sotto le tue informazioni.

Per presentare te stesso

Crea un sito di una sola pagina per presentarmi a chi potrebbe offrirmi un lavoro o affidarmi un incarico. Non è un curriculum: non fare un elenco dei lavori che ho fatto. La pagina deve far capire chi sono, che cosa so fare, che cosa offro e che cosa mi appassiona. Usa solo le informazioni che trovi sotto e non inventare niente: se un'informazione manca, non metterla. Metti le parti in quest'ordine: in alto il mio nome e una frase su che cosa offro; poi che cosa so fare; poi l'esempio di lavoro fatto bene; poi chi sono e le mie passioni; infine i contatti, con un invito a scrivermi. Usa uno stile semplice e ordinato, che si legga bene anche sul telefono. Scrivi tutto in un solo file HTML, senza file esterni, e dammi il file HTML da scaricare. Le mie informazioni:

Crea un sito di una sola pagina per presentare la mia attività ai clienti. La pagina deve far capire che cosa offriamo, chi siamo e che cosa ci distingue. Usa solo le informazioni che trovi sotto e non inventare niente: se un'informazione manca, non metterla. Usa uno stile semplice e ordinato, che si legga bene anche sul telefono. Scrivi tutto in un solo file HTML, senza file esterni, e dammi il file HTML da scaricare. Le informazioni sull'attività:

Passo 3 · Scarica, apri, controlla

Segui i passi di «Dalla risposta dell'IA al desktop». Chiama il file, per esempio, presentazione.html. Poi controlla:

  1. Ogni frase è vera? Confronta la pagina con le informazioni che hai scritto. L'IA tende ad aggiungere frasi che non hai scritto, come «professionista appassionato» o «sempre orientato al cliente».
  2. Sembra un curriculum? Se la pagina è soprattutto un elenco di date e aziende, chiedi all'IA di rifarla mettendo al centro che cosa sai fare e che cosa offri.
  3. Manca qualcosa? Controlla che ci siano le cose che sai fare, l'esempio, le passioni e i contatti.
  4. Si legge sul telefono? Restringi la finestra del browser trascinando il bordo: il testo deve andare a capo e non deve uscire dalla pagina.

Passo 4 · Correggi e migliora

Una richiesta alla volta, nella stessa chat. Dopo ogni modifica scarica il file nuovo e sostituisci quello vecchio.

Togliere le frasi vuote

Togli dalla pagina tutte le frasi generiche che non dicono niente di concreto, come «appassionato», «dinamico» o «orientato ai risultati». Tieni solo le informazioni che ti ho dato. Dammi il file HTML completo.

Pulsante per scrivere un'email

Aggiungi nei contatti un pulsante «Scrivimi» che, quando lo premo, apre il programma di posta con il mio indirizzo email già inserito. Dammi il file HTML completo.

Colori

Cambia i colori della pagina: blu scuro per i titoli e per la parte in alto, sfondo bianco, testo grigio scuro. Non cambiare i testi. Dammi il file HTML completo.

Riquadri per le cose che sai fare

Mostra le cose che so fare (o i servizi) in riquadri affiancati, tre per riga; sul telefono i riquadri devono andare uno sotto l'altro. Non cambiare i testi. Dammi il file HTML completo.

Una foto

Aggiungi in alto una foto rotonda. La foto si chiama foto.jpg e si trova nella stessa cartella del file HTML. Dammi il file HTML completo.

Con la foto i file diventano due. Crea sul desktop una cartella, per esempio sito, e metti dentro sia il file HTML sia foto.jpg. Se li separi, la foto non si vede.

Metterlo su internet. Per ora il sito si apre solo sul tuo computer. Per renderlo visibile a tutti serve un servizio che lo pubblichi (per esempio GitHub Pages o Netlify, che hanno piani gratuiti). In questo esercizio non lo facciamo.
